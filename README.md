# AI Career Platform

An AI-powered career platform that helps users:

- Parse CVs
- Parse Job Descriptions
- Match candidates with jobs
- Identify transferable skills
- Recommend career paths
- Generate tailored CVs
- Generate cover letters
- Build personalized learning roadmaps

## Tech Stack

- n8n
- Anthropic Claude
- Supabase
- Lovable
- Docker
